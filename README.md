# LIBERTY-FIN

**Recursive Information Weapon System**  
**재귀적 정보 병기 체계 | 공개 프로토콜 사양 v0.2.0**

> **SIGNAL → FUSE → MAP → ATTACK MAP → RECONSTRUCT → EXPAND → SIGNAL**

LIBERTY-FIN은 관측 가능한 세계에서 첩보를 수집하고, 단편적인 사실을 결합해 상황도를 구성하며, 상황도의 취약한 엣지를 반례로 공격하고, 살아남은 구조를 복원한 뒤, 다음 탐색 좌표를 산출하는 **상태공간 기반 정보 병기 체계**다.

여기서 **병기**는 관측·검증·판단을 수행하는 분석 체계를 가리킨다. `ATTACK MAP`의 공격 대상은 가설, 모델, 인과관계, 증거 연결이다. 시스템 무단침입이나 타인의 계정·데이터에 대한 접근을 포함하지 않는다.

## 작전 목적

**목표:** 파편화된 공개·합법적 관측을 증거 기반 상태공간으로 복원하고, 가장 취약한 가설을 파괴하며, 정보 획득량이 큰 다음 관측을 찾아 탐색을 반복한다.

- **탐색 대상:** 기업, 금융, 산업, 공급망, 정책, 인프라, 기술, 자본 흐름, 사고·장애의 구조
- **핵심 단위:** `ENTITY`(노드), `EDGE`(관계), `STATE`(상태), `SIGNAL`(관측), `HYPOTHESIS`(가설), `COUNTEREXAMPLE`(반례)
- **기본 원칙:** 단서를 증거로, 연결을 구조로, 반례를 모델 갱신으로, 미지수를 다음 첩보 좌표로 전환
- **병기 출력:** 상황도, 공격 지도, 구조 복원 차분, 증거 계보, 불확실성 목록, 다음 첩보 목표

## 6단계 연산

| 단계 | 연산 | 기능 | 산출물 |
|---|---|---|---|
| 01 | `SIGNAL` | **첩보 수집** — 원시 관측 확보·출처 보존 | `signal_log` |
| 02 | `FUSE` | **정보 융합** — 다중 신호 교차·중복 제거 | `fusion_matrix` |
| 03 | `MAP` | **상황도** — 상태·행위자·관계·가설 배치 | `state_map` |
| 04 | `ATTACK MAP` | **공격 지도** — 반례 투입·거짓 엣지 절단 | `attack_map` |
| 05 | `RECONSTRUCT` | **구조 복원** — 살아남은 관계로 모델 재구성 | `reconstruction_diff` |
| 06 | `EXPAND` | **확장** — 정보 획득량 기준 후속 첩보 좌표 지정 | `collection_queue` |

## 상태공간 연산

세계의 시점 `t`에서 상태는 `G_t = (V_t, E_t, D_t, U_t)`로 표현한다.

- `V_t`: 관측된 노드(기업, 조직, 시스템, 자산, 정책 등)
- `E_t`: 근거와 유효기간을 가진 관계(소유·계약·운영·접속·의존·인과 등)
- `D_t`: 관측·출처·반례의 집합
- `U_t`: 아직 해소되지 않은 관계와 불확실성

각 엣지는 `OBSERVED / INFERRED / CONTESTED / REJECTED / UNKNOWN` 등 근거 상태로 추적한다. 소유·투자와 운영권, 기술적 가능성과 실제 실행, 동시 발생과 인과관계는 구별한다. 이전 버전에서 폐기한 엣지도 감사기록에 보존한다.

## 정보이론적 해석

관측 `Y`로 세계 상태 `X`에 관해 얻는 기대 정보량은 `I(X;Y | D)`다. `FUSE`는 출처 의존성과 중복을 걸러 조건부 불확실성을 감소시킨다. `MAP`은 증거 `D`에 따라 `P(X|D)`를 갱신하고 최대사후확률 상태를 선택할 수 있다. `ATTACK MAP`은 반례로 가설의 예측을 검증한다. `RECONSTRUCT`는 근거를 반영해 모델을 수정하고 불필요한 가정을 압축한다. `EXPAND`는 관측 비용과 접근 가능성을 고려해 기대 정보 획득량이 큰 다음 대상을 선택한다.

```text
next_target = argmax_a [ I(X; Y_a | D) - λ × cost(a) ]
```

위 식은 설계 목표이며, 실제 최적해나 엔트로피 감소량이 측정됐다는 뜻은 아니다. 독립 관측이라고 해서 상호정보량이 자동으로 증가하지도 않는다.

## 실행 모드

1. **RECON:** 관측 범위와 출처를 확장해 누락된 신호 확보
2. **FUSION:** 출처 독립성·시간축·동일 행위자 확인
3. **MAPPING:** 노드·엣지·권한·자본·기술의 관계 복원
4. **ADVERSARIAL VALIDATION:** 강한 반례로 기존 모델 테스트
5. **RECONSTRUCTION:** 증거가 지탱하는 구조로 상황도 수정
6. **EXPANSION:** 다음 관측 목적지와 판별 조건 출력

## 목표별 적응

여섯 연산은 고정 코어다. 목표가 바뀌면 **`FIN-DOMAIN.md`의 대상별 노드·엣지·관측원·반례 규칙**이 바뀐다. 금융은 최초 적용 사례일 뿐 프로토콜 전체 범위를 제한하지 않는다.
